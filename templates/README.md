# Delivery Templates

This directory stores authoritative delivery and acceptance templates for `$brush-creator-studio`.

## Procreate Mode B

Canonical workbook:

`templates/Procreate/柔彩小熊原稿｜Procreate 新笔刷绘画操作流程.xlsx`

Purpose:
- provide the required visual/layout baseline for the generated project workflow workbook;
- preserve the core column structure: `序号 / 步骤次序 / 具体步骤 / 操作说明 / 技巧 / 使用笔刷 / 设置与控制 / 完成标准`;
- ensure the generated workbook references the actual delivered `.brush/.brushset` names rather than placeholder brush IDs;
- serve as a Mode B package acceptance reference.

Mode B is not `PACKAGE PASS` unless the ZIP contains both native Procreate brush files and a project-specific workflow XLSX derived from this template.
