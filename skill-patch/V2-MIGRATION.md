# $brush-creator-studio V2.0.0 Migration

V2 supersedes the V1.1 Remote Resolver Patch and V1.3 quantity-only runtime logic. The remote resolver remains, but the quantity model is now bidirectional:
- Redundancy Check prevents excess brushes.
- Undercoverage Review prevents missing/over-merged brushes.

Canonical rules are now in repository `SKILL.md` + `knowledge/RUNTIME-CONTRACT.md`.

Major additions:
1. Artwork Complexity Profile
2. Full Production Stage Decomposition
3. Object / Material Map
4. Brush Role Inventory
5. Brush Specialization Gate
6. Multi-dimensional Merge Eligibility Gate
7. Undercoverage Review
8. Complexity Sanity Check
9. Mode B Native Delivery Gate requiring actual `.brush + .brushset + XLSX`
10. V2 valid Procreate XLSX template

Old patch files are historical only and must not override V2 canonical rules.
